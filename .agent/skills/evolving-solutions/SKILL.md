# Evolving Solutions

Use this skill when combining lessons from multiple candidates into a stronger follow-up candidate.

## Inputs

- Current goal
- Candidate comparison report
- Candidate diffs or summaries
- Evaluation results
- Policy outcomes

## Procedure

1. Identify the strongest candidate and the specific reasons it is strongest.
2. Identify partial wins from weaker candidates.
3. Exclude changes that failed policy, broke tests, or contradicted human decisions.
4. Create a recombination plan that lists what to keep, discard, and rewrite.
5. Implement the smallest coherent candidate that combines the useful ideas.
6. Run required checks and record lineage as `combined_with` or `inspired_by`.

## Outputs

- Recombination plan
- New candidate summary
- Lineage relationships
- Evaluation results

## Rubric

- The combined candidate is simpler than the union of all attempted patches.
- Known failures are not reintroduced.
- Lineage is explicit.
- The candidate can be reviewed as a normal patch.

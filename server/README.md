# Server

This directory is reserved for the ClimbHill MCP server package layout described in the project goal.

Current local MVP implementation lives in:

- `climbhill/mcp_server.py`
- `climbhill/registry.py`
- `climbhill/policy.py`
- `climbhill/resources.py`
- `climbhill/reports.py`

The intended server package structure is kept here so future implementation work can move or wrap the Python MVP without changing the public product boundary.

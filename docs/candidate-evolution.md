# Candidate Evolution

Candidate evolution helps agents generate and improve solution attempts across repeated runs.

## Run Modes

- Single candidate mode
- Parallel candidate mode
- Historical sampling mode
- Recombination mode
- Meta-analysis mode

## Lineage Relationships

- `forked_from`
- `inspired_by`
- `combined_with`
- `supersedes`
- `reverted_from`
- `failed_due_to`
- `promoted_from`

Lineage should be explicit so future agents can understand why a candidate exists and what prior evidence it used.

# Codex Plugin

The Codex plugin is the first-class distribution package for ClimbHill.ai workflows.

Current scaffold:

- `plugin/climbhill-ai/.codex-plugin/plugin.json`
- `plugin/climbhill-ai/.mcp.json`
- `plugin/climbhill-ai/README.md`
- `plugin/climbhill-ai/install.md`
- `plugin/climbhill-ai/skills/`

The plugin should eventually provide:

- MCP server configuration.
- Commands for initializing a repo.
- Access to ClimbHill skills.
- Default policy templates.
- Default evaluation templates.
- Example improvement workflows.

The plugin should make ClimbHill easy to add to an existing repository without hiding the workflow from the user.

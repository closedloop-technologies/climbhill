# Falsify

Actively try to kill an important assumption or the whole plan before investing
further.

## Goal

Counter confirmation bias by searching for the strongest evidence that the
current hypothesis, route, or business should not continue.

## Flow

1. State the claim whose failure would materially change the plan.
2. Write the strongest credible failure hypothesis or null explanation.
3. Identify the observations that would be difficult to explain if the current
   claim were true.
4. Research existing contradictory evidence first.
5. If the answer is still empirical, use Experiment to create the cheapest
   credible test of the failure hypothesis.
6. Use Evidence to evaluate both supporting and contradicting observations,
   confounders, and alternative explanations.
7. Update the plan explicitly: continue, change the hypothesis, reduce scope,
   gather more evidence, or stop.
8. If used inside Wayfinder, let the result update the map and expose the next
   frontier rather than manufacturing another test automatically.

The purpose is not pessimism. It is to make survival of a hypothesis informative.
A hypothesis that cannot in principle lose is not ready for this workflow.
